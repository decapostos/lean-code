# Lean Code

A minimal-code coding skill derived from [Ponytail](https://github.com/dietrichgebert/ponytail) by Dietrich Gebert.

Lean Code helps AI coding agents avoid unnecessary complexity by prioritizing:

- Existing code over new code
- Standard library over custom implementations
- Native platform features over new dependencies
- The smallest practical implementation
- YAGNI and deletion over unnecessary abstraction

It preserves the core methodology while removing code-level watermarking and branding.
